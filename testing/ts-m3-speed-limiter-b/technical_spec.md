# spec: Urban Bus Speed Limitation Device (SLD)

## Product Type

An electronic speed limitation device that continuously monitors vehicle speed and limits the engine's power/road speed to a set maximum for an urban bus.

## Vehicle Category

M3 — fitted to a rigid or articulated urban bus used for city passenger transport.

## Function

- Continuously reads vehicle road speed from the driveline/tachograph speed signal.
- Compares actual speed with the configured maximum limitation speed.
- Reduces engine torque/fuel delivery (or commands the powertrain) to prevent exceeding the set limit.
- Provides a self-test and fault indication when the speed signal or limiter circuit fails.
- Enables a certified workshop to set and seal the limitation speed.

## Main Parts

- Electronic control unit (limiter module) with sealed speed setting.
- Speed signal interface harness to the vehicle's speed sensor/tachograph.
- Actuator interface to the engine control unit (torque reduction request).
- Dashboard status/fault indicator.
- Sealing and calibration access port.
