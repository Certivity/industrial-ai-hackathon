# spec: Connected Passenger Car with Cyber Security Management and Over-the-Air Software Update

## Product Type

A passenger car whose electronic systems are covered by a manufacturer cyber security management system (CSMS) and which can receive software updates over-the-air (OTA). The vehicle is a finished product placed on the market with network connectivity and remote update capability.

## Vehicle Category

M1 — a passenger car with no more than eight seats in addition to the driver seat, fitted with an on-board communication/telematics unit and updatable electronic control units.

## Function

- Provides networked connectivity for telematics, diagnostics and software update delivery.
- Manages, receives, verifies and installs OTA software updates on in-vehicle ECUs.
- Protects vehicle systems against cyber threats through a managed cyber security process.
- Reports and handles update failures or rollback to a safe state.
- Notifies the driver/owner of pending updates and their effect on vehicle use.

## Main Parts

- Telematics/connectivity control unit (TCU).
- OTA update client and update host with secure boot.
- Diagnostic and gateway ECU.
- In-vehicle network (CAN/Ethernet) with secured access.
- Human–machine interface for update notification.
